# 03_Resources — 参考資料・ナレッジ

特定案件に紐づかない汎用ナレッジを置きます。テンプレート・プレイブック・製品情報。

## サブ領域

| ディレクトリ | 内容 |
| --- | --- |
| `templates/` | 議事録・提案書・スライド原稿の雛形 |
| `playbooks/` | 業種別・フェーズ別の営業プレイブック |
| `products/` | 自社プロダクトの仕様・FAQ・競合比較（営業トーク用） |

## 運用ルール

- ここのファイルは「再利用」前提。特定顧客名・案件名は書かない
- テンプレートはフロントマターのキーを **コメントで説明** すること（コピー時に迷わないように）
